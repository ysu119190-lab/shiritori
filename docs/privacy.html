プライバシーポリシー

制定日: 2026年8月13日

本ポリシーは、iOS アプリ「しりとり」（以下「本アプリ」）における利用者情報の取り扱いを定めるものです。

1. 開発者が収集する情報

本アプリは、アカウント登録が不要で、開発者が氏名・メールアドレス等の個人情報を収集・保存することはありません。プレイヤー名・対戦履歴・設定・ポイントなどのゲームデータは、すべてお使いの端末内にのみ保存されます。

2. 広告について

本アプリは、広告配信のために Google AdMob（Google LLC が提供する広告サービス）を使用しています。AdMob は広告の配信・計測のために、広告識別子（IDFA など）や端末情報等を自動的に取得する場合があります。これらの情報の取り扱いについては、以下をご参照ください。

  • Google プライバシーポリシー
  • Google の広告に関するポリシーと規約

3. 通信について

本アプリは、入力された単語が実在するかを判定するため、必要な場合に限り、入力された単語（ひらがな）を Wikipedia（ウィキメディア財団）の公開 API に送信することがあります。送信されるのは判定対象の単語のみで、個人を特定できる情報は含まれません。

4. 情報の第三者提供

開発者が利用者の個人情報を第三者に販売・提供することはありません。前述の広告配信・単語判定に伴う通信は、各サービス提供者のポリシーに従って行われます。

5. お子様の利用について

本アプリは幅広い年齢の方に安心してお使いいただけるよう、開発者による個人情報の収集を行わない設計としています。

6. ポリシーの変更

本ポリシーの内容は、必要に応じて変更されることがあります。重要な変更がある場合は、本ページにて告知します。

7. お問い合わせ

本ポリシーおよび本アプリに関するお問い合わせは、以下の GitHub Issues までお願いします。
