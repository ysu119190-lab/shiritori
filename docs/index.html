しりとり

友達とあそべる、ことばゲーム

「しりとり」は、1台の iPhone を交代しながら 2〜6 人で遊べる、しりとり専用アプリです。ルールの判定はぜんぶアプリにおまかせ。ことば遊びに集中できます。

特長

  • 同じ端末をまわして 2〜6 人で対戦（パス＆プレイ）
  • 約 46,000 語の辞書で、単語が実在するかを自動判定
  • 文字数制限や「毎ターンお題の文字数がランダムに変わる」モード
  • 「ん」で終わったら負け・重複禁止・長音や小さい文字のルールも自動判定
  • 予測変換で答えがバレない、アプリ内かなキーボード（フリック / 50音）
  • 困ったときのヒント機能、対戦の中断・再開、しりとりポイント集め
  • 1手ごとの制限時間（オプション）
