## 2. 説明（4,000文字以内）

```
「しりとり」は、ルールの判定をぜんぶアプリにおまかせできる、しりとり専用アプリです。
「それ本当にある言葉？」「今なんの音からだっけ？」で止まらずに、ことば遊びそのものを楽しめます。


■ 4つのあそびかた

・ひとりで（CPU対戦）
　よわい／ふつう／つよいの3段階。かんたんに勝てない歯ごたえのある相手です。
　勝敗と連勝がずっと記録されるので、コツコツ強くなっていけます。

・みんなで（パス＆プレイ）
　1台のiPhoneを回して2〜6人で対戦。集まったその場ですぐ遊べます。

・近くの人と対戦
　同じ部屋にある2台を直接つないで1対1。それぞれの手元の画面で遊べます。

・はなれた人と対戦（Game Center）
　友だちを招待して、順番に単語を送り合うターン制。
　相手がオフラインでも大丈夫。返ってきたときに続きから遊べます。


■ ぜんぶ自動で判定します

・その単語が実在するか
　約46,000語の辞書を内蔵。ほとんどの言葉はインターネットなしで即判定します。
　辞書にないキャラクター名なども、設定をオンにすればウェブで調べられます。

・しりとりのルール
　前の単語の最後の音から始まっているか／「ん」で終わっていないか／
　もう使った単語でないか、を自動でチェックします。

・まぎらわしいルールも
　長音「ー」（コーヒー→「ひ」でも「い」でもOK）、
　小さい文字（おちゃ→「や」）、濁点の扱い（か→が を許すかどうか）まで対応。


■ ルールは自由に決められます

・文字数のしばり（最小・最大）
・毎ターン、お題の文字数がランダムに変わるモード（幅も指定できます）
・1手ごとの制限時間
・濁音・半濁音を区別するかどうか
・辞書になくても、参加者みんなが認めればOKにする設定


■ 遊びやすさのくふう

・予測変換が出ないアプリ内キーボード（フリック／50音）
　ふつうのキーボードだと、変換候補で次の手が相手にバレてしまうことがあります。
・こまったときのヒント（答えは教えず、文字数と終わりの音だけ）
・対戦の中断と再開
・遊ぶほど貯まる「しりとりポイント」でアイコンを集められます


■ こんなときに

・家族や友だちと集まったとき
・移動中や待ち時間のひまつぶしに
・お子さんのことば遊びに（漢字は使わず、ぜんぶひらがなです）


ことば遊びの時間を、判定でモメずにたっぷり楽しんでください。
```

> 注: 辞書データは mecab-ipadic（IPA辞書）を利用しています。
> 著作権表示はアプリ内（Resources/ipadic-COPYING.txt）とリポジトリに同梱済み。

## 6. App プライバシー（データ収集の申告）

**アプリ本体は個人情報を一切収集しない。** ただし広告SDK（Google AdMob）が
データを扱うため、以下を申告する。

### 「データを収集していますか？」→ **はい**（AdMobを使っているため）

| データの種類 | 収集 | 用途 | ユーザーに紐付け | トラッキング |
|---|---|---|---|---|
| 識別子 → デバイスID | ✅ | サードパーティ広告 | いいえ | **いいえ** |
| 使用状況データ → 広告データ | ✅ | サードパーティ広告 | いいえ | **いいえ** |
| 診断 → クラッシュ／パフォーマンス | 任意 | アプリの機能 | いいえ | いいえ |

> **「トラッキング」を「いいえ」にする根拠**: 本アプリは
> AppTrackingTransparency（ATT）の許可を求めておらず、IDFA を用いた
> クロスアプリ追跡を行わない。AdMob は許可がなければ非パーソナライズ広告として動作する。
>
> ⚠️ 将来ATTを導入してパーソナライズ広告を有効にする場合は、
> この申告を「トラッキング: はい」に変更し、ATTの許可ダイアログ実装が必須になる。

### 収集しないもの（明確に「いいえ」）

- 連絡先情報（氏名・メール・電話番号）
- 位置情報
- 連絡先・写真・ファイル
- 検索履歴・閲覧履歴
- 購入履歴

```
本アプリは日本語の「しりとり」ゲームです。アカウント登録は不要で、
すべての機能をサインインなしでお試しいただけます。

【対戦モードについて】
1. ひとりで（CPU対戦）: すぐに動作を確認できます。
2. みんなで（パス＆プレイ）: 1台の端末で交代して遊ぶモードです。
3. 近くの人と対戦: MultipeerConnectivity を使い、同じネットワーク上の

   初回起動時にローカルネットワークの許可を求めます。
4. はなれた人と対戦: Game Center のターン制マッチを使います。
   確認には Game Center へのサインインが必要です。

【ネットワーク通信について】
- 単語が実在するかの判定は、内蔵辞書（約46,000語）でオフラインに行います。
- 設定で「ウェブ（Wikipedia）でも調べる」をオンにした場合のみ、
  入力された単語（ひらがな）を Wikipedia の公開APIに送信して記事の有無を
  確認します。ブラウザ表示は行わず、個人情報は送信しません。
- 広告配信のため Google AdMob を使用しています。

【辞書データの出典】
内蔵辞書は mecab-ipadic (IPA辞書) の読みデータから生成しています。
ライセンス表記はアプリバンドル内に同梱しています。
```

### 撮る画面（おすすめの順番と文言）

1. **対戦画面**（大きな「ご」バッジ＋履歴）
   キャプション: 「つぎの音がひと目でわかる」
2. **設定画面**（あそびかたの4択が見えるところ）
   キャプション: 「ひとりでも、みんなでも」
3. **CPU対戦中**（考えています…の表示、または連勝表示）
   キャプション: 「CPUと腕試し。連勝記録に挑戦」
4. **近くの人と対戦のロビー**
   キャプション: 「近くの2台をつないで対戦」
5. **アプリ内キーボード**（フリック）
   キャプション: 「予測変換が出ないから、手の内がバレない」
6. **結果画面**（かち！＋ポイント）
   キャプション: 「勝ってポイントを集めよう」

### 撮り方（自動）

**GitHub Actions で自動撮影できます。**

1. Actions → **Store Screenshots** → Run workflow
2. 撮影する端末（`both` / `iphone` / `ipad`）を選んで実行
3. 完了後、artifact **store-screenshots** をダウンロード
4. 中の PNG をそのまま App Store Connect にアップロード

仕組み: Debug ビルドをシミュレータに入れ、起動引数 `-screenshotScene <名前>` で
目的の画面を直接開かせて `simctl io screenshot` で撮ります。
内容は固定（プレイヤー名「さくら / ゆうと」、しりとりの履歴も固定）なので、
何度撮っても同じ絵になります。ステータスバーも 9:41・電波満タンに揃えられます。

撮れる画面: `setup` / `game` / `keyboard` / `nearby` / `solo` / `help` / `result`

> 実行結果のサマリーに**画像サイズの一覧**が出ます。
> App Store の要求サイズ（iPhone 6.9" = 1320x2868 / iPad 13" = 2064x2752）と
> 一致しているか確認してください。ランナーのシミュレータ構成によっては
> 別サイズになることがあります。

> 撮影用のコードは `#if DEBUG` で囲まれており、**リリースビルドには含まれません**。
